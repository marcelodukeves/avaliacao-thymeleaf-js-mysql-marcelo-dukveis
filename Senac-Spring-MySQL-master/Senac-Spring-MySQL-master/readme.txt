Projeto: senac-crud
Autor: Marcelo Dukeveis
Java: 21
Framework: Spring Boot 3
Banco: MySQL 8 (root/root)
Descrição: CRUD simples de Pessoas com JPA e Thymeleaf

Como rodar:
1. Crie o banco no MySQL:
   CREATE DATABASE senac_crud;

2. Abra o projeto no IntelliJ.
3. Verifique se o SDK está configurado como Java 21.
4. Rode a classe SenacCrudApplication.java.
5. Acesse http://localhost:8080/pessoas
